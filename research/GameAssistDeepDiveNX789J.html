Master Plugin Visibility Pipeline

Every plugin goes through a three-stage filter before appearing in the game sidebar:

R.string.plugin_list_tiles → Utils.d() — ZteFeature removal → PluginConfig.l() — enable + space + whitelist

Stage 1: Utils.k() reads R.string.plugin_list_tiles (a comma-separated list baked into the APK), parses it into an ArrayList.

Stage 2: Utils.d() removes plugins whose ZteFeature flags are false. This is the hard gate — if your flag defaults to false and the device doesn't set it, the plugin is gone.

Per-Plugin Detail

link_mics_translation

Real-time voice translation during gaming. Communicates with com.zte.aitranslation via ContentProvider calls: "switch_open", "switch_close", "GameUpdate". Sends the current game package name and user ID. Not gated by any ZteFeature flag — if it's in the plugin_list_tiles string resource, it appears. State tracked per-package via nubia_ai_translation_enabled_pkg (comma-separated list). AI agent commands: game_turn_on_game_voice_translation, game_turn_off_game_voice_translation.

barrage_message

Danmaku/bullet-screen message overlay. The simplest tile in the entire APK — a pure Settings.Global toggle with zero external dependencies. Flips gsc_barrage_message between 0 and 1. No ZteFeature gate, no whitelist, no external service. Another system component reads the setting to display the overlay.

voice_controller

Hard-gated by ZTE_FEATURE_GAMEASSIST_VOICE_CONTROLLER (default false) in Utils.d(). Sends intents to com.zte.onemorething / com.zte.aispeaker.aigc.AudioRecordService with three actions:

  • com.zte.onemorething.action.START_ASR — start speech recognition
  • com.zte.onemorething.action.STOP_ASR — stop recognition
  • com.zte.onemorething.action.EDIT_VOICE_CONTROLLER — open settings

Coordinates with GameVoiceController policy class. Per-package state in voice_controller_enabled_pkg.

game_browser

Uses GameThirdAppTitle — a generic tile class shared across 7+ plugins (game_bilibili, game_douyin, game_kuaishou, game_qq, game_wechat, game_whatsapp). It's a quick-launch button that opens the third-party app in a floating window. The specific package is resolved from the plugin name via TilesUtil.l(). For "game_browser", it launches cn.nubia.browser (RedMagic) or com.ume.browser (ZTE/other) determined by ZteFeature.getBrowserPackage(). Supports dual-app detection (WeChat/QQ clones). No ZteFeature gate in Utils.d() — always present.

low_sugar

Low-sugar gameplay mode — appears to be a fatigue/health monitoring feature. Uses LowSugarComService via Router pattern. The ZteFeature check ZTE_FEATURE_LOW_SUGAR (default false) is not in Utils.d() but is checked inside the tile's own k0() (AI agent command handler) before processing voice commands. Monitors com.zte.aispeaker.contentProvider for AIGC user login state — requires cloud AI account login. State in nubia_low_sugar_gameplay_pkg_open. Checks nubia_account_login_status for auth.

Per-Feature Detail

ai_detect

Real-time enemy/object detection overlay. AiDetectTile is a simple toggle that writes Settings.Global "game_foot_ai_detect" = 0 or 1. The actual YOLOX inference runs in a separate service that reads this setting. The tile itself has no direct model interaction — it just signals. Gate: removed by Utils.G() which returns true unless ZteFeature.isSupportSoundProbe() AND the current game is com.tencent.tmgp.pubgmhd. This means ai_detect only shows for PUBG Mobile (Chinese) when sound probe is enabled — a very narrow gate.

Whitelist from config XML: pubgmhd, krmobile, ig, vng.pubgmobile, pubg.newstate, rekoo.pubgm — all PUBG variants.

ai_tip / tactical_coach

Strategic game advice delivered in real-time. AITipTile sends intents to cn.zte.gamefloat with action cn.zte.gamefloat.ai.tip. Events: "open", "close", "set" (edit settings), "request_tip". Gate: ZTE_FEATURE_GAME_AI_TIPS (default false). Label dynamically changes on SDK ≥ 36 to "tactical coach". Per-package state in game_ai_tip_enable_pkgs.

domestic sgame, pubgmhd, lolm, Yuanshen, cf, cod, jkchess

game_prediction

Win-rate prediction overlay. GamePredictionTile starts cn.zte.gamefloat.wrp.WinRatePredictionService with the current game package. Auto-starts 800ms after game launch if enabled. The win rate value is read from Settings.Global "game_predication_value" (float 0.0–1.0, displayed as percentage). Gate: ZTE_FEATURE_AI_GAME_PREDICTION (default false).

Whitelists from config:
domestic sgame, lolm, cf, jkchess
international freefireth, freefiremax, mobile.legends

hunting_mode

Not an AI/ML feature — it's a display color filter. Sets game_strengthen_mode_value to 5 (hunting = mode 5) and broadcasts cn.nubia.intent.action.game_color_invert. Extends FloatButtonQSTile for a floating toggle button overlay. If ZteFeature.isSupportGameDisplayFilterEffect() is true, hunting_mode is removed from Utils.d() and replaced by the gameshader plugin.

Whitelist from config: pubgmhd, hyxd, ko, krmobile, ig, vng.pubgmobile, pubg.newstate, rekoo.pubgm, iglite, pubg.imobile
