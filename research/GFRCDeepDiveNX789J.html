Architecture

The Call Chain

When a game launches, the system queries whether it supports GFRC. The call originates in framework.jar and resolves through IPC into cubeserver.jar, which holds the actual implementation.

MindSyncManager$Trigger → getGfrcCapByPkgImpl → IMindSyncManager (IPC) → E.getGfrcCapByPkg → N.j(pkg)

private static int getGfrcCapByPkgImpl(IMindSyncManager service, String pkgName) {
    if (service != null) {
        try {
            int cap = service.getGfrcCapByPkg(pkgName);
            Slog.d(TAG, "getGfrcCapByPkg, pkgName=" + pkgName + ",cap=" + cap);
            return cap;
        } catch (RemoteException e) {
            Log.e(TAG, e.getMessage(), e);
            return 0;
        }
    }
    return 0;
}

Implementation — GfrcModeCtrl

The Binder call lands in PerformanceController (obfuscated class E), which forwards to GfrcModeCtrl (class N). This class loads the whitelist from a config file and performs the actual lookup.

cn.nubia.server.cube.plugs.N (GfrcModeCtrl) Core lookup · line 328 
public int j(String str) {
    // If vendor.gpp.allgame.enable == 1, ALL games get full cap (22)
    if (1 == SystemProperties.getInt("vendor.gpp.allgame.enable", 0)) {
        return 22;
    }
    // Otherwise, look up in the HashMap loaded from gpp_app_list
    Integer num = this.e.get(str);
    if (num != null) {
        return num.intValue();
    }
    return 0; // not whitelisted
}

The return value encodes two capabilities as a single integer: (upscale × 10) + interp. A return of 21 means upscale=2 + interp=1. A return of 0 means the game is not whitelisted. The special value 22 (when vendor.gpp.allgame.enable=1) enables full SR + interp for every game.

Config File Parsing

cn.nubia.server.cube.plugs.N (GfrcModeCtrl) Startup loader · line 230 
private void p() {
    BufferedReader reader = new BufferedReader(
        new FileReader("/system/etc/gpp_app_list"));
    String line;
    while ((line = reader.readLine()) != null) {
        String trimmed = line.trim();
        if (!TextUtils.isEmpty(trimmed) && !trimmed.startsWith("#")) {
            String[] parts = trimmed.split(",");
            if (parts.length == 3) {
                // Store as: (upscale * 10) + interp
                this.e.put(parts[0],
                    (Integer.parseInt(parts[1]) * 10)
                  + Integer.parseInt(parts[2]));
            }
        }
    }
    reader.close();
}
